2026，个人 AI 技术栈最小清单

一、基础语言与运行环境（只选一个） ✅ Python（唯一推荐）

二、模型层（云优先，不造模型） ✅ 大模型 API（选 2 个即可）

主模型（稳定干活）

GPT-4.x / GPT-4o

Claude 3.5

GLM-4 / DeepSeek（性价比）

副模型（便宜 / 批量）

GPT-4.1-mini / DeepSeek-chat / GLM-Flash

你需要掌握的不是模型，而是：

prompt 结构化

function / tool calling

成本与延迟控制

三、Agent 与编排层（核心战场） ✅ LangGraph（主力）

这是你2026 年最重要的工具之一。

你要学的不是 API，而是思想：

State（状态）

Node（能力）

Edge（决策流）

Retry / Branch / Loop

👉 本质：把“思考流程”变成可执行图 可选补充

LangChain（只用工具封装）

自写轻量 Agent（理解本质）

四、工具层（让 AI 真正“能干活”）

这是 AI 是否落地的分水岭。

必备工具类型 1️⃣ 数据工具

SQL（DuckDB / SQLite）

CSV / Parquet 读取

pandas（基础即可）

2️⃣ 文件工具

本地文件读写

Markdown / PDF 解析（够用即可）

3️⃣ 外部 API

Web search（可选）

Notion / GitHub / Google Docs（视场景）

原则： 先服务你自己，再考虑通用性

五、记忆与上下文管理（克制使用） ✅ 最小方案

文件型 memory（JSON / YAML / SQLite）

手动分：

session memory

long-term memory

❌ 暂不需要

向量数据库

RAG 大工程

复杂 embedding pipeline

90% 的个人项目，用不到向量库 用了反而让系统不可控

六、工程与项目结构（避免“写成一坨”） 推荐最小项目结构 ai-agent-project/ ├─ agents/ │ ├─ planner.py │ ├─ executor.py │ └─ critic.py ├─ tools/ │ ├─ sql_tool.py │ └─ file_tool.py ├─ graphs/ │ └─ main_graph.py ├─ memory/ │ └─ memory.json ├─ configs/ │ └─ prompts.yaml ├─ main.py └─ README.md

必须有 README，哪怕只有 10 行。

七、部署与展示（能跑就赢 80%） 最小可用方案

本地 CLI / Streamlit

或简单 Web UI（FastAPI + HTML）

❌ 暂不需要

Kubernetes

高并发

企业级部署

一句话：“能被别人跑起来的 Demo，胜过 10 个想法。”

八、版本管理与输出（身份构建关键） 必须做

Git + GitHub

每个项目一个 repo

清晰 commit

强烈建议

写技术笔记 / 项目复盘

哪怕只给“未来的你”看

九、你现在不需要的东西（帮你挡坑）

请你放心地 不学、不买、不碰：

❌ 显卡

❌ 模型训练

❌ CUDA

❌ 超复杂 RAG

❌ 多框架对比

❌ AI “课程囤积”

最后，给你一个“今晚就能用”的起手式

今晚任务（≤ 2 小时）：

新建一个 repo

写 README 第一行：

“这个项目的目标是：把 __ 经验，做成一个可运行的 AI Agent。”

不写代码也没关系，但这个 repo 一旦存在—— 你已经上路了。
