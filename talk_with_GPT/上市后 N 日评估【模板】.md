# ✅ **一、总体逻辑结构（全局示意）**

上市后 12 天，要回答 4 个核心问题：

1. **卖得怎么样？**（销量表现）
2. **卖给谁？怎么卖的？**（用户画像 + 渠道）
3. **和竞品比怎么样？**（对比与竞争压力）
4. **为什么？还能怎么优化？**（归因 + 建议）

> 这些问题分别对应不同的指标体系 & 分析框架。

## \*\*📌 表：汽车行业上市后 12 天表现评估

指标体系 × 分析框架对照表（完整）\*\*

| **业务角度（问题）**             | **指标体系（WHAT — 衡量什么）**                                                     | **分析框架（HOW — 怎么分析）**                                                           | **说明 / 输出（SO WHAT）**                             |
| -------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| **1. 销售表现：卖得怎么样？**    | - 累计零售量<br>- 日度零售走势<br>- 大区/省份销量分布<br>- 渗透率（对所在级别份额） | **趋势分析**（日度走势）<br>**分层分析**（区域、渠道）<br>**贡献度分析**（增量来自哪里） | 识别“上市热度是否符合预期”；找到贡献最大的区域和异常点 |
| **2. 订单与线索：热度够不够？**  | - 订单量<br>- 线索量（试驾、留资）<br>- 试驾转化率<br>- 订单交付比                  | **漏斗分析（线索 → 订单 → 交付）**                                                       | 判断是否“流量不够”还是“转化不健康”；识别瓶颈环节       |
| **3. 用户画像：谁在买？**        | - 年龄、性别<br>- 城等级分布<br>- 竞品替代来源<br>- 置换 vs 首购比例                | **结构对比**（实际 vs 期望 vs 竞品）<br>**分群分析**                                     | 判断核心用户是否符合产品定位；识别增长潜力群体         |
| **4. 渠道表现：怎么卖出去的？**  | - 各渠道订单占比（直营/经销/线上）<br>- 门店试驾量<br>- 门店成交率                  | **分层分析（渠道维度）**<br>**转化率拆解**                                               | 找到效率低的渠道、门店；判断是否需要价格动作或培训动作 |
| **5. 竞品对比：比别人强吗？**    | - 对标竞品销量<br>- 同级别上市同期表现<br>- 价格带竞争格局                          | **横向对比**<br>**竞争格局分析（Price–Volume Map）**                                     | 发现竞争压力点；判断是否需要促销或配置调整             |
| **6. 宣发表现：声量是否转化？**  | - 内容曝光量<br>- 搜索指数<br>- 互动率<br>- KOL/自媒体声量                          | **声量 → 线索转化分析**<br>**A/B 活动对比**                                              | 判断营销 ROI 是否健康；识别优质渠道                    |
| **7. 原因分析：为什么好/不好？** | - 影响因子：价格、供应、渠道、竞品动作、营销节奏                                    | **因果树分析（Cause–Effect Tree）**                                                      | 明确关键原因：是供应？渠道？竞品？需求？               |
| **8. 改进行动：怎么办？**        | - 可执行指标：试驾提升、价格动作、渠道培训、区域压力管理                            | **优先级框架（ICE / RICE）**                                                             | 输出可落地的行动闭环和未来 7–14 天监控项               |

# ✅ 三、如果写成《上市 12 天表现评估》报告，它会长这样

（概要结构）

---

### **1. 总览（Executive Summary）**

- 上市 12 天累计零售：XX
- 达成率：XX%
- 热度优于/低于预期
- 关键驱动因素：XX、XX
- 下一步动作：XX、XX

---

### **2. 销售表现（指标 + 框架：趋势分析 + 分层分析）**

- 日度销售曲线
- 区域贡献度
- 零售 vs 批售节奏
- 对比竞品表现

---

### **3. 线索与订单（指标 + 框架：漏斗分析）**

- 曝光 → 线索 → 试驾 → 订单 → 成交
- 瓶颈定位
- 与目标的 GAP

---

### **4. 用户画像（指标 + 框架：分群分析 + 对比分析）**

- 年龄、城市级别
- 实际 vs TA 匹配度
- 竞品替代来源

---

### **5. 渠道表现（指标 + 框架：渠道分层 + 转化拆解）**

- 门店表现差异
- 成交率低的渠道
- 提升路径建议

---

### **6. 竞品分析（指标 + 框架：横向对比）**

- 同级别新车对比
- 竞品节奏与促销动作

---

### **7. 关键原因（指标 + 框架：因果树）**

- A 类因素（正向）
- B 类因素（负向）
- 核心结论

---

### **8. 下一步行动（框架：优先级 + 闭环）**

- 未来 7–14 天重点指标
- 立即落地的动作清单
