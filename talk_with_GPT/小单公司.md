tableau 和数据分析咨询的小单业务

（1）Tableau 报表制作 / 仪表盘开发

交付内容：
数据清洗 + 可视化
3 ～ 5 个工作表
1 套 Dashboard 模板
客单价： ¥1,000–8,000

特点： 周期短、可复用模板、重复购买率高。
（2）企业小型数据诊断（2–3 小时的咨询）

内容：
业务场景分析
数据字段结构诊断
KPI 建议
可视化建议
含录制视频或会议纪要
客单价： ¥800–3,000
（3）ETL 小流程梳理（使用 Tableau Prep / Python）

内容：
自动化清洗流程
简单调度
输出干净数据集
客单价： ¥2,000–10,000

特点： 企业痛点明确，但内部缺乏人做。
（4）培训类小单（Tableau 基础课 / KPI 课）

内容：
2 ～ 3 小时
录屏 + 文件
交付一个简单项目作业
客单价： ¥1,500–5,000（个人）企业内训： ¥6,000–15,000 / 场
如何获取前 10 个客户？（切实可操作）

1）知乎/小红书写 5 篇案例（最有效）

标题示例：
《一个仪表盘帮企业节省 20 小时/周》
《中小公司如何用 Tableau 做月度复盘？》
《老板最喜欢的 7 个 KPI Dashboard 模板》
每篇文底部留一句：

接受 Tableau / 数据咨询的小型项目。

会有自然流量找你。
2）在即刻 / 微信社群投放一句介绍

例如：

「承接 Tableau 小单，报表开发 1–3 天交付。」

不用硬推，客户自己来。
3）做一个“模板商店”

做 3 个可视化模板，用以演示：
销售 Dashboard
财务 Dashboard
运营 Dashboard
直接展示你的交付能力。
4）朋友圈持续发布“你最近做过的东西”

不是营销，是展示能力。

只需要坚持两周，就会有企业来问。
✅ 五、交付流程（非常关键）

一个成熟的咨询师都有固定流程，你可以用：
Kickoff meeting（30 min）需求对齐 → 字段清单 → 业务问题
数据抽样分析（0.5 ～ 1 天）找字段问题 → 发现 KPI
原型 Dashboard（0.5 天）低保真，用于对齐思路
最终 Dashboard（1–2 天）上线可用版本
录屏讲解（避免后期支持过多）
这样：
周期短
客户满意度高
你自己能做更多单
特点： 零开发、纯咨询、毛利极高。
